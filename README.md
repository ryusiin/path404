# path404

카약을 위아래로 움직여 다가오는 장애물을 피하는 브라우저 게임 아이디어입니다.

## 지금 해볼 수 있는 것

초기 프로토타입에서는 오른쪽에서 파이프가 반복해서 다가옵니다. 카약을 움직여 파이프를 피하는 타이밍을 시험해 볼 수 있습니다.

1. 저장소를 내려받고 `path404.html`을 브라우저에서 엽니다.
2. **↑ 위쪽 화살표**를 누르면 카약이 위로 뛰어오릅니다.
3. **↓ 아래쪽 화살표**를 누르면 카약이 아래로 잠수합니다.
4. 동작이 끝나면 카약은 원래 높이로 돌아옵니다.

현재 버전은 조작과 장애물 움직임을 확인하는 실험용입니다. 충돌 판정, 점수, 게임 오버는 아직 구현되어 있지 않습니다.

## 앞으로의 계획

path404는 나중에 새로 개발할 게임 프로젝트입니다. 현재 코드는 초기 아이디어를 기록해 둔 프로토타입이며, 새 버전의 개발은 아직 시작하지 않았습니다.
